# 🤖 Custom Discord Bot - Python

Un bot Discord multifunzionale sviluppato in Python utilizzando `discord.py`.

## ✨ Caratteristiche principali
- 🎟️ **Sistema di Ticket:** Permette agli utenti di aprire ticket di supporto privati con lo staff.
- 🛠️ **Moderazione:** Comandi per kick, ban, mute e pulizia chat (`!clear`).
- 👋 **Welcome System:** Messaggi di benvenuto automatici e assegnazione ruoli iniziale.
- ⚙️ **Comandi Utilità:** Info server, info utente e ping del bot.

## 🛠️ Tecnologie Utilizzate
- **Python 3.x**
- **discord.py**
- **python-dotenv**
